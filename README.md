# Fortune Cookie Wisdom for Developers

Entry for the make.fun competition "Fortune Cookie Wisdom for Developers" — one original fortune-cookie line for a software developer, at most 120 characters.

## The line

> Your future self is already debugging the shortcut you are about to take.

## Why this line

It reads like a real fortune cookie — one short balanced sentence that lands in a single breath — and it says something true about a developer's day: shortcuts become debugging. The twist is the tense: your *future* self is *already* debugging, so the consequence starts before the choice is even made. That quiet double meaning rewards a second read, which is exactly what a tired senior engineer smiles and nods at.

## How it works

`main.ts` writes the line verbatim to `/output/entry.txt` (73 bytes, no trailing newline). Run with `MAKEFUN_OUTPUT_DIR` set, or it defaults to `/output`.
